# 黄色小宠物 · Windows 桌面宠物

用你给的那张角色图做的桌面宠物：**窗口全透明、无边框、始终置顶**，
画面保留原来的**桌子、鼠标垫、键盘、鼠标**（只把紫色背景扣掉），
**桌宠的手会抓着那只鼠标动** —— 光标往右滑动，画面里的鼠标就带着爪子往左滑（反方向），
手臂像橡皮筋一样从肩膀拉伸出去，手一直按在鼠标上，活动范围限制在鼠标垫那一带。

## 直接运行

双击 **`dist\黄色小宠物.exe`**（约 520 KB）。

* 单文件、免安装，三个精灵图（场景 / 手臂 / 权重图）都编译进 EXE 里；
* 不需要 Python、不需要 .NET SDK —— 只用 Windows 自带的 .NET Framework 4.x
  （Win8 / Win10 / Win11 都自带）。

## 它能做什么

| 操作 | 效果 |
| --- | --- |
| **移动真实鼠标** | 桌宠的手抓着鼠标朝光标**反方向**滑动（光标往右 → 里的鼠标往左，光标往左 → 往右）；光标离得远时，手停在鼠标垫离光标最远的那一侧 |
| 按住**左键拖动** | 把整块「桌宠 + 桌子」拖到桌面任意位置 |
| **右键**桌宠 / 托盘图标 | 菜单：`大小`（小 / 中 / 大 / 特大）、`退出` |
| 点击透明的地方 | 点到下面的窗口或桌面（不会挡住你干活） |
| 退出后再启动 | 记住上次的**大小**和**位置** |

其它特性：

* 逐像素透明（不是抠色）：紫色背景的地方完全透明，深色 / 浅色壁纸都没有紫边；
* 无边框、不在任务栏留按钮（托盘有一个小图标，右键可退出）；
* DPI 自适应，125% / 150% 缩放的屏幕上也保持正常观感；
* 只在光标移动时才重画，静止时几乎不占 CPU（实测约 0.5%，光标连续移动时约 3%）。

## 手是怎么「抓着鼠标动」的

原理是把画面拆成两层：

1. **场景层**：整张图，扣掉紫色背景；把「左手臂 + 爪子 + 鼠标」这一块挖掉，
   挖掉的地方用背景补回来 —— 桌沿那条粗黑线的走向、鼠标垫的灰度渐变，
   都是从旁边没被挡住的一列像素**沿直线平移**采样回来的，所以补丁和周围完全接得上。
   手臂原来占住的、属于身体的那半块（肩窝），用身体剩余部分的**凸包**补齐，
   颜色从同一行身体像素横向延伸过去，再补一条黑色描边 —— 所以手挪开时身体是完整的，
   不会出现一个切口。
2. **手臂层**：被挖出来的那一块（连同鼠标），每一帧按一个**权重图**做变形：
   权重在肩膀处是 0、在爪子处是 1，于是手臂靠近肩膀的部分不动（接缝看不出来），
   越靠近爪子位移越大 —— 手臂被自然拉长，手始终牢牢按在鼠标上。

位移量 = 光标位置（换算到画面坐标）先夹到鼠标垫范围内、再取**反方向**，
最后在「沿手臂方向 / 垂直手臂方向」两个方向上限幅，避免手臂被压扁或拉伸过头
（实测最多约 130 px）。

## 重新构建

```powershell
# 1)（可选）重新生成精灵图：需要一个装了 Pillow + numpy 的 python
python assets\step7_scene.py

# 2) 编译 EXE
powershell -NoProfile -ExecutionPolicy Bypass -File build\build.ps1
```

`build.ps1` 只是调用 `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe`，
把 `assets\sprites\scene.png`、`arm.png`、`armw.png` 以资源形式嵌进 EXE，`pet.ico` 作为程序图标。

> 想换素材的话，把同名的 `scene.png` / `arm.png` / `armw.png` 放到 EXE 旁边，
> 程序会优先读旁边的文件（不用重新编译）。

## 实现要点（`src/YellowPet.cs`）

* 一个 `WS_EX_LAYERED` 窗口，用 `UpdateLayeredWindow`（`ULW_ALPHA`）贴预乘 alpha 的 32 位位图；
* 每帧：把上一帧手臂占的矩形从场景层恢复 → 用权重图做两次不动点迭代求逆映射 →
  双线性采样手臂层并用预乘 alpha 合成 → 推给窗口；光标不动就不重画；
* 桌宠窗口处理 `WM_NCHITTEST`：**透明像素返回 `HTTRANSPARENT`**，点击直接穿到下层；
* 拖动：`WM_LBUTTONDOWN` 记下光标与窗口位置，`WM_MOUSEMOVE` 时
  `窗口 = 起点 + (当前光标 - 起点光标)`，并 `SetCapture` 保证拖出窗口也不丢；
* 右键菜单用原生 `CreatePopupMenu` / `TrackPopupMenuEx`（无焦点窗口也能正常工作）。
